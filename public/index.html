How it got there

    How it works

    • A single agent with three tools: search the corpus, read a document section, list the documents.
    • It retrieves, checks whether the evidence is enough, and searches again if not. Capped at 3 rounds.
    • When two versions of a document conflict, the most recent effective date governs.
    • Citations are checked in code against the sections actually retrieved in that run.

    Atlas Underwriting is fictional; the corpus is seven made-up documents. Source, evals, and design notes on GitHub.
